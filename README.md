# GG Open Watchparty 2026 — Claude Code handoff

Portable handoff repository for the social/video production titled **Watchparty in der GG Open Lobby**.

- Canvas: 1080×1350 portrait
- Event: Saturday, 14 November 2026, 19:00 / 20:00
- Location: Hauptstraße 240, Herne
- Admission: free entry
- Creative direction: GG Open identity, editorial arena geometry, supplied Watch Party logo
- Renderer: local SVG/HTML and Chromium; no image-generation model or paid generation

Start with [`HANDOFF.md`](HANDOFF.md). It defines the facts, design constraints, source map, render commands, font licensing, and acceptance checklist. Absolute server paths are isolated in [`LOCAL_SOURCES.md`](LOCAL_SOURCES.md) and are not required for portable use.

- `assets/final/` — final slide SVG/HTML/PNG, corrected motion exports, supplied logo source and reference post
- `assets/source/` — structural direction sources (A_DIAGONAL, B_SPLIT, C_RADIAL)
- `brand/logos/` — only relevant GG Open identity-core logos
- `fonts/Poppins/` — Poppins under SIL Open Font License 1.1
- `skills/` — selected Grafiker/Videograf skills with attribution and source paths
- `HANDOFF.md` — operational brief for Claude Code
- `LOCAL_SOURCES.md` — local-only provenance paths

The old dark-sci-fi/generic-placeholder outputs are intentionally not included and are **NO-GO** references.
